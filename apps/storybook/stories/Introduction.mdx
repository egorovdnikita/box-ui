# Box UI

Дизайн-токены и иконки, сгенерированные прямо из файла Figma «Foundation – Core» —
1118 переменных в 15 коллекциях. Каждая **мода переменных** выведена в переключатель на
панели сверху.

| Коллекция Figma                     | Моды                                                      | Переключатель     |
| ----------------------------------- | --------------------------------------------------------- | ----------------- |
| ◉ Primitives ・ Color / Spacing / Rounding / Size / Typography | только _Value_                 | —                 |
| ◑ System ・ Color                   | только _Value_                                            | —                 |
| ☯︎ Brand ・ Color                    | Deep, Bright, Monochrome                                  | `data-accent`     |
| ☯︎ Brand ・ Rounding                 | Low, Medium, High                                         | `data-radius`     |
| ☯︎ Brand ・ Typography               | Inter, Inter Display, Inter Tight, Inter Variable         | `data-font`       |
| ☯︎ Brand ・ Icon                     | Bold, Bold Duotone, Broken, Line Duotone, Linear, Outline | `data-icon-style` |
| ◑ System ・ Theme                   | Light, Dark                                               | `data-theme`      |
| ◑ System ・ Responsive              | Desktop, Mobile                                           | `data-device`     |
| ◑ System ・ Status                  | Positive, Warning, Negative, Information                  | `data-status`     |
| ◑ System ・ Controls ・ Appearance   | Solid, Soft, Outline                                      | `data-appearance` |
| ◑ System ・ Controls ・ State        | Default, Hover, Active, Disabled                          | `data-state`      |

## Как разрешается токен

Ничего не дублируется под каждую тему. Каждый алиас Figma становится переходом `var()`,
поэтому переключение моды на `<html>` заново разрешает всю цепочку — ровно как смена моды
в самой Figma.

```
--accent-fill-solid   [data-theme]   System · Theme
  └─ var(--brand-color-solid-500) [data-accent]  Brand · Color
       └─ var(--color-indigo-500)          Primitives · Color (фиксировано)
            └─ #6366f1
```

У контролов над этим ещё два переключаемых слоя — и ни один не описан в CSS компонента
повторно:

```
--control-accent-fill   [data-state]   Controls · State
  └─ var(--control-appearance-accent-fill-default)  [data-appearance]  Controls · Appearance
       └─ var(--interaction-accent-solid-fill-default)  [data-theme]  System · Theme
            └─ … → var(--color-indigo-500)
```

С размерами то же самое, только со стороны скруглений на уровень глубже:

```
--rounding-xl   [data-device]  System · Responsive  Desktop → xl, Mobile → l
  └─ var(--brand-rounding-xl)  [data-radius]  Brand · Rounding   Low 20 · Medium 24 · High 32
       └─ var(--rounding-20)                             Primitives · Rounding
            └─ 20px
```

## Как это применять

```tsx
import '@box-ui/tokens/css';
import { Card, Text } from '@box-ui/react';
import { Icon } from '@box-ui/icons';

<html data-theme="dark" data-accent="bright" data-radius="high" data-device="mobile">
  <Card>
    <Icon name="check-circle" size="m" />
    <Text variant="h4">Готово</Text>
  </Card>
</html>;
```

### Переключение мод для части страницы

Кастомное свойство подставляется **там, где объявлено**, а не там, где прочитано. Чтобы
переключить моды для поддерева, поставьте на один элемент _все_ атрибуты — тогда каждый
слой переобъявляется здесь же и цепочка разрешается локально. Переопределение одного лишь
`data-accent` глубже по дереву не дотянется до токена темы, который предок уже разрешил.

```html
<div
  data-theme="dark"
  data-accent="bright"
  data-radius="high"
  data-font="inter"
  data-device="desktop"
  data-status="positive"
  data-appearance="solid"
  data-state="default"
></div>
```

Из этого же правила следует, почему каждый контрол сам несёт `data-appearance` и
`data-state`: без них вид и состояние разрешались бы на предке. По той же причине
`controls.css` переобъявляет на каждом контроле те 18 переменных темы, что ведут в
коллекцию «Status», — иначе `data-status` на самом контроле ничего бы не менял.

`@box-ui/tokens/css/adaptive.css` необязателен: он берёт тёмную тему из
`prefers-color-scheme`, а Mobile — ниже 768px, но только когда документ сам не выставил эти
атрибуты.

## Куда смотреть

- **Начало работы** — установка, подключение мод, использование токенов и иконок.
- **Токены** — все 15 коллекций Figma так же, как на страницах документации в файле: группы по пути, значение в каждой моде, code syntax и описание.
- **Основы** — наглядно: палитра, светлая и тёмная тема рядом, текстовая шкала и шкалы отступов, скруглений и размеров.
- **Иконки** — 1300+ иконок Solar в шести стилях и семейства «Флаги / Платежи / Бренды».

Переключатели на панели управляют всеми токенами на этих страницах, поэтому любая история
заодно работает превью моды. Сами страницы намеренно окрашены в собственные цвета
Storybook — переключатели меняют содержимое Box UI, а не документацию вокруг него.

Отдельные разделы про моды и компоненты появятся, когда появятся компоненты.
