# Box UI

Дизайн-токены и иконки, сгенерированные прямо из трёх библиотек Figma. Каждая **мода
переменных** выведена в переключатель на панели сверху.

| Файл Figma           | Коллекция                                                   | Моды                                                                  | Переключатель         |
| -------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------- | --------------------- |
| Box UI \| Primitives | Color Palette, Spacing, Rounding, Size, Opacity, Typography | только _Value_                                                        | —                     |
| Box UI \| Tokens     | **Color**                                                   | Blue, Sky, Teal, Emerald, Orange, Amber, Violet, Purple, Cyan, Yellow | `data-accent`         |
| Box UI \| Tokens     | **Mode**                                                    | Light, Dark                                                           | `data-theme`          |
| Box UI \| Tokens     | **Rounding**                                                | Low, Medium, High                                                     | `data-radius`         |
| Box UI \| Tokens     | **Typography**                                              | Inter, Inter Display, Inter Tight, Inter Variable                     | `data-font`           |
| Box UI \| Tokens     | **Grid**                                                    | Desktop, Mobile                                                       | `data-device`         |
| Box UI \| Icons      | **Icon**                                                    | Bold, Bold Duotone, Broken, Line Duotone, Linear, Outline             | `<IconStyleProvider>` |

## Как разрешается токен

Ничего не дублируется под каждую тему. Каждый алиас Figma становится переходом `var()`,
поэтому переключение моды на `<html>` заново разрешает всю цепочку — ровно как смена моды
в самой Figma.

```
--box-background-sentiment-primary   [data-theme]    Mode
  └─ var(--box-colors-brand-primary) [data-accent]   Color
       └─ var(--box-color-blue-solid-500)            Color Palette (фиксировано)
            └─ #3b82f6
```

С размерами то же самое, только со стороны скруглений на уровень глубже:

```
--box-rounding-base-xl   [data-device]  Grid     Desktop → base/xl, Mobile → base/l
  └─ var(--box-radius-base-xl)  [data-radius]  Rounding  Low 20 · Medium 24 · High 32
       └─ var(--box-rounding-24)                          Rounding (примитив)
            └─ 24px
```

## Как это применять

```tsx
import '@box-ui/tokens/css';
import { Button, Card, Text } from '@box-ui/react';
import { Icon } from '@box-ui/icons';

<html data-theme="dark" data-accent="violet" data-radius="high" data-device="mobile">
  <Card>
    <Text variant="h4">Готово</Text>
    <Button startIcon={<Icon name="check-circle" size="2xs" />}>Продолжить</Button>
  </Card>
</html>;
```

### Переключение мод для части страницы

Кастомное свойство подставляется **там, где объявлено**, а не там, где прочитано. Чтобы
переключить моды для поддерева, поставьте на один элемент _все пять_ атрибутов — тогда
каждый слой переобъявляется здесь же и цепочка разрешается локально. Переопределение
одного лишь `data-accent` глубже по дереву не дотянется до токена Mode, который предок уже
разрешил.

```html
<div data-theme="dark" data-accent="violet" data-radius="high" data-font="inter" data-device="desktop"></div>
```

`@box-ui/tokens/css/adaptive.css` необязателен: он берёт тёмную тему из
`prefers-color-scheme`, а Mobile — ниже 768px, но только когда документ сам не выставил эти
атрибуты.

## Куда смотреть

- **Начало работы** — установка, подключение мод, использование токенов и иконок.
- **Основы** — сырая палитра, текстовая шкала и шкалы отступов, скруглений, размеров и прозрачности.
- **Иконки** — 1300+ иконок Solar в шести стилях и семейства «Флаги / Платежи / Бренды».

Переключатели на панели управляют всеми токенами на этих страницах, поэтому любая история
заодно работает превью моды. Сами страницы намеренно окрашены в собственные цвета
Storybook — переключатели меняют содержимое Box UI, а не документацию вокруг него.

Отдельные разделы про моды и компоненты появятся, когда появятся компоненты.
