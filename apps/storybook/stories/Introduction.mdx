# Box UI

Дизайн-токены и иконки, сгенерированные прямо из файла Figma «Foundation – Core». Каждая
переменная Figma становится CSS-переменной с тем же именем, что в её Code syntax, а каждая
мода — атрибутом на `<html>`.

<Stats />

## Три слоя токенов

Алиасы идут сверху вниз: компонент берёт семантический токен из **System**, тот ссылается
на характер бренда в **Brand**, а бренд — на сырое значение в **Primitives**. Клик по
коллекции открывает её таблицу.

<LayerMap />

## Как разрешается токен

Ничего не дублируется под каждую тему. Каждый алиас Figma становится переходом `var()`,
поэтому смена моды на `<html>` заново разрешает всю цепочку — ровно как в самой Figma.

```
--accent-fill-solid                [data-theme]   System · Theme
  └─ var(--brand-color-solid-500)  [data-accent]  Brand · Color
       └─ var(--color-indigo-500)                 Primitives · Color
            └─ #6366f1
```

С размерами так же, только слоёв на один больше — устройство переназначает ступень:

```
--rounding-xl                      [data-device]  System · Responsive   Desktop → xl, Mobile → l
  └─ var(--brand-rounding-xl)      [data-radius]  Brand · Rounding      Low 20 · Medium 24 · High 32
       └─ var(--rounding-20)                      Primitives · Rounding
            └─ 20px
```

У контролов сверху ещё два переключаемых слоя — вид и состояние:

```
--control-accent-fill                                  [data-state]       Controls · State
  └─ var(--control-appearance-accent-fill-default)     [data-appearance]  Controls · Appearance
       └─ var(--interaction-accent-solid-fill-default) [data-theme]       System · Theme
            └─ … → var(--color-indigo-500)
```

## Моды в этом Storybook

Кнопка **Моды** на панели сверху переключает их все сразу. Первая группа — тема, акцент,
скругление, гарнитура, устройство и стиль иконок — меняет всё, что нарисовано Box UI на
этих страницах. Вторая — статус, вид и состояние — доходит только до токенов контролов.
Сами страницы окрашены в цвета Storybook, поэтому моды меняют содержимое, а не
документацию вокруг него. В таблицах токенов каждая колонка показывает свою моду
независимо от выбранной.

### Моды для части страницы

Кастомное свойство подставляется **там, где объявлено**, а не там, где прочитано. Чтобы
переключить моды в поддереве, поставьте на один элемент _все_ атрибуты: тогда каждый слой
переобъявится здесь же. Один лишь `data-accent` глубже по дереву не дотянется до токена
темы, который предок уже разрешил. `BoxUIProvider` из `@box-ui/react` делает это сам.
