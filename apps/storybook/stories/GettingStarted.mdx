# Начало работы

Три пакета, и ни в одном нет литерального цвета, радиуса или размера: всё приходит из
переменных Figma через `@box-ui/tokens`.

## 1. Установите

```bash
npm i @box-ui/tokens @box-ui/icons @box-ui/react
```

## 2. Подключите CSS

```js
import '@box-ui/tokens/css';
```

Это `primitives.css` — фиксированные значения на `:root` — и `theme.css`, по блоку на
каждую моду Figma, которые выбираются атрибутами `data-*`. Их можно подключить и по
отдельности.

Необязательно — моды из настроек системы:

```js
import '@box-ui/tokens/css/adaptive.css';
```

Тёмная тема берётся из `prefers-color-scheme`, Mobile — ниже 768px, **но только если
документ сам не выставил эти атрибуты**.

## 3. Выберите моды

Каждая переключаемая коллекция Figma — один атрибут. Выделено значение по умолчанию.

<ModeTable />

Поставьте атрибуты на `<html>` — и за ними пойдёт весь документ:

```html
<html data-theme="dark" data-accent="bright" data-radius="high" data-device="mobile"></html>
```

Или пусть это сделает провайдер:

```jsx
import { BoxUIProvider } from '@box-ui/react';

<BoxUIProvider target="root" theme="dark" accent="bright" radius="high">
  <App />
</BoxUIProvider>;
```

По умолчанию `target="local"`: провайдер оборачивает детей в `<div>` со всеми атрибутами —
так две темы уживаются на одной странице.

## 4. Пользуйтесь токенами

В CSS — по имени из Code syntax в Figma:

```css
.card {
  background: var(--surface-base-fill-raised);
  color: var(--surface-base-content-strong);
  border-radius: var(--rounding-m);
  padding: var(--spacing-m);
}
```

Или из JS, с автодополнением:

```js
import { theme, layout } from '@box-ui/tokens';

theme.surface.base.fill.raised; // 'var(--surface-base-fill-raised)'
layout.spacing.base.m; // 'var(--spacing-m)'
```

В `model` лежит весь граф — коллекции, моды и то, на что ссылается каждая переменная. Из
него собраны таблицы этого Storybook.

## 5. Иконки

```jsx
import { Icon, IconStyleProvider } from '@box-ui/icons';

<Icon name="home-smile" size="l" title="Home" />

<IconStyleProvider style="bold-duotone">
  <Icon name="shield-check" size="m" />
</IconStyleProvider>;
```

Размеры — токены `size/base/*`, поэтому иконка слушается `data-device`, а красится она
`currentColor`. Каждый стиль — отдельный `import()`: приложение везёт только то, что рисует.
Без `title` иконка скрыта от вспомогательных технологий — так и нужно для декоративных.
