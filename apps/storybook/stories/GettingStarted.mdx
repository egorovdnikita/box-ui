# Начало работы

Три пакета, и ни в одном нет литерального цвета, радиуса или размера: всё приходит из
переменных Figma через `@box-ui/tokens`.

```bash
npm i @box-ui/tokens @box-ui/icons @box-ui/react
```

## 1. Подключите CSS

```js
import '@box-ui/tokens/css';
```

Это `primitives.css` (777 фиксированных значений на `:root`) плюс `theme.css` (по блоку на
каждую моду Figma, выбираются атрибутом `data-*`). Их можно импортировать по отдельности,
если нужен только один.

Дополнительно:

```js
import '@box-ui/tokens/css/adaptive.css';
```

Он берёт тёмную тему из `prefers-color-scheme`, а Mobile — ниже 768px, **но только если
документ сам не выставил эти атрибуты**.

## 2. Выберите моды

Каждая переключаемая коллекция Figma соответствует одному атрибуту:

| Атрибут | Коллекция Figma | Значения | По умолчанию |
| --- | --- | --- | --- |
| `data-theme` | System · Theme | `light` `dark` | `light` |
| `data-accent` | Brand · Color | `indigo` `lime` `yellow` `pink` `monochrome` | `indigo` |
| `data-radius` | Brand · Rounding | `low` `medium` `high` | `low` |
| `data-font` | Brand · Typography | `inter` `inter-display` `inter-tight` `inter-variable` | `inter` |
| `data-device` | System · Responsive | `desktop` `mobile` | `desktop` |
| `data-status` | System · Status | `positive` `warning` `negative` `information` | `positive` |
| `data-appearance` | Controls · Appearance | `solid` `soft` `outline` | `solid` |
| `data-state` | Controls · State | `default` `hover` `active` `disabled` | `default` |

Поставьте их на `<html>` — и за ними пойдёт весь документ:

```html
<html data-theme="dark" data-accent="pink" data-radius="high" data-font="inter" data-device="desktop">
```

Или пусть это сделает провайдер:

```jsx
import { BoxUIProvider } from '@box-ui/react';

<BoxUIProvider target="root" theme="dark" accent="violet" radius="high">
  <App />
</BoxUIProvider>;
```

`target="local"` — значение по умолчанию — вместо этого оборачивает детей в `<div>`, и
именно так две темы уживаются на одной странице.

## 3. Пользуйтесь токенами

В CSS, по имени:

```css
.card {
  background: var(--box-surface-base-fill-raised);
  color: var(--box-surface-base-content-strong);
  border-radius: var(--box-rounding-base-m);
  padding: var(--box-spacing-base-m);
}
```

Или из JS, если не хочется набирать имена руками:

```js
import { color, layout } from '@box-ui/tokens';

color.background.base.secondary; // 'var(--box-surface-base-fill-raised)'
layout.spacing.base.m; // 'var(--box-spacing-base-m)'
```

В `model` лежит весь граф — коллекции, моды и то, на что ссылается каждая переменная.
Именно из него собраны эти страницы документации.

## 4. Иконки

```jsx
import { Icon, IconStyleProvider } from '@box-ui/icons';

<Icon name="home-smile" size="l" title="Home" />

<IconStyleProvider style="bold-duotone">
  <Icon name="shield-check" size="m" />
</IconStyleProvider>;
```

Размеры — токены `size/base/*`, поэтому иконка слушается `data-device` наравне со всем
остальным, а геометрия красится `currentColor`. Каждый стиль — отдельный динамический
`import()`, так что приложение везёт только то, что рисует.

Без `title` иконка скрыта от вспомогательных технологий — это то, что нужно для
декоративных; передавайте `title`, когда смысл несёт именно иконка.
