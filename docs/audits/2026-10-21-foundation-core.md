# Аудит Box UI — состояние на 21.10.2026

Источник: Figma Foundation – Core (`gbgGmuUBQ7sIfL256KaDXX`) и этот репозиторий. История аудитов 19–21.10 сведена сюда; ниже — текущее состояние, решения и открытые пункты.

## Состояние

- **Переменные:** 15 коллекций, 1118 переменных. Битых алиасов 0, литералов выше Primitives 0 (кроме строк Brand · Typography и Brand · Icon — см. решения), `ALL_SCOPES` 0, переменных без описания или code syntax 0, дублей code syntax на всех платформах 0, расхождений «путь ↔ Web-имя» 0.
- **Шкалы:** типографика монотонна в Desktop/Mobile, line-height ≥ font-size; spacing / size / rounding монотонны во всех сочетаниях Desktop/Mobile × Low/Medium/High.
- **Тёмная тема:** совпадает со светлой только намеренно (`achromatic/*`, полупрозрачные нейтральные обводки).
- **Документация в Figma:** 15 страниц, 36 таблиц DocTable. Строки совпадают с переменными один в один, данные ячеек (цели алиасов, литералы, code syntax, HEX и прозрачность примитивов) совпадают. Цветовые образцы привязаны к своей коллекции и рисуются в моде своей колонки. Переопределений имён, отвязанных стилей, скрытых слоёв и пустых слотов 0.
- **Репо:** дампы и `meta.json` совпадают с Figma (последняя синхронизация 21.10). Payments: 676 иконок, коллизий имён и slug нет, одна монета — одна запись.
- **Иконки:** графика семейств — экспорт из Figma (`packages/icons/figma/`): Flags 179 из 197, Payments 675 из 676, Brands 24 из 24. Остальные — на запасной открытой графике (см. «Открыто»).
- **UI-иконки:** 1253 иконки страницы `System` в 37 категориях, имена уникальны, у всех шесть стилей в одном порядке. Пакет и Storybook повторяют состав, имена и категории Figma; геометрия — Solar, сверенная с Figma по контурам, и экспорт Figma для 7 иконок, которых в Solar нет.

## Отклонено или оставлено владельцем

- Контраст `status/content/on-solid` на `status/fill/solid` ниже AA (2.6–3.8 при норме 4.5) — риск на стороне продукта.
- Regular-вес, тени, border-width.
- Мода Status `Information` при шкале System · Color `informative`.
- Неиспользуемая проводка: Brand · Color `inverse/alpha/8`, `inverse/contrast`, `on-solid-alpha/80` (+inverse); System · Color `neutral/300`, `positive/500`, `warning/500` — оставлены ради полноты шкал (проверено по всем 37 модам).
- Повторяющиеся описания у шагов примитивов — допустимы.
- Избыточные шкалы примитивов — оставлены как палитра (в пикерах не видны).
