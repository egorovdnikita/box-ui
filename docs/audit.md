## Отклонено или оставлено владельцем

- Контраст `status/content/on-solid` на `status/fill/solid` ниже AA (2.6–3.8 при норме 4.5) — риск на стороне продукта.
- Regular-вес, тени, border-width.
- Мода Status `Information` при шкале System · Color `informative`.
- Неиспользуемая проводка: Brand · Color `inverse/alpha/8`, `inverse/contrast`, `on-solid-alpha/80` (+inverse); System · Color `neutral/300`, `positive/500`, `warning/500` — оставлены ради полноты шкал (проверено по всем 37 модам).
- Повторяющиеся описания у шагов примитивов — допустимы.
- Избыточные шкалы примитивов — оставлены как палитра (в пикерах не видны).
