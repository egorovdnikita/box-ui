# Промо box-ui для README

Запись настоящего Storybook: Playwright проходит сценарий реальными кликами и вводом с клавиатуры в Chromium, снимает окно 1440 × 810 в Retina 2x после каждого шага, а монтаж кладёт снимки окном на фон и ведёт камеру. Курсора нет, клики показаны кольцами в измеренных центрах настоящих элементов. Контент — только то, что есть в Storybook; сетевых запросов, кроме локального сервера на `127.0.0.1`, нет.

Результат: зацикленный WebP 1600 × 900, 30 кадров/с, около 37 с и 18 МБ. Фон GitHub Dark `#0d1117`, обводка `#3d444d`, скругление 20 pt. Первый и последний кадры совпадают: сценарий сам возвращает Storybook в исходное состояние («Сбросить» в «Модах» и переход на исходную страницу).

```sh
npm run build:storybook
python3 -m venv /tmp/box-ui-promo-env
/tmp/box-ui-promo-env/bin/pip install playwright pillow
/tmp/box-ui-promo-env/bin/playwright install chromium
/tmp/box-ui-promo-env/bin/python scripts/promo/promo.py /tmp/box-ui-promo
cp /tmp/box-ui-promo/box-ui-demo.webp docs/assets/box-ui-demo.webp
```

Временные файлы — в папке из первого аргумента, вне репозитория: `shots/` — снимки шагов, `script.json` — сценарий с точками кликов, `keys/` — контрольные кадры с шагом 0,5 с, `verification.json` — длительность, клики и сверка первого и последнего кадров.

`--only-compose` монтирует заново из уже снятых `shots/`; `--keys-only` рисует только контрольные кадры без кодирования.

## Сжатие

WebP с потерями, качество 90 (`--quality`). Без потерь (`--lossless`) ролик весит около 2,5 МБ на секунду движения камеры, то есть больше 60 МБ. Кодирует libwebp напрямую через Pillow, а не ffmpeg: у `libwebp_anim` включён `minimize_size`, и на светлом фоне после исчезновения инспектора оставался его бледный след. Здесь ключевые кадры идут каждые 3–5 кадров, и следа нет.

## Сценарий

System · Theme в тёмной теме → «Моды»: тема Light и иконки Linear → переход по алиасу `color/neutral/100` в System · Color и дальше в Primitives · Color, копирование `var(--color-neutral-100)` → Иконки · System: поиск «heart», инспектор Heart и переключение стилей → сброс фильтров и мод, возврат к началу.
